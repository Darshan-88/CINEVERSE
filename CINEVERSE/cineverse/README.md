# CINEVERSE
Node.js 20.12+ movie discovery website. Copy .env.example to .env and set TMDB_API_KEY to your private v3 key. Run `npm start` and open http://localhost:3000. No dependencies required. For Vercel import the repository as Other framework, set TMDB_API_KEY in project environment variables, and deploy. Static files and api/movies.js are served directly by Vercel. Personal ratings and watchlist are local to the browser. Movie ratings are TMDB, not IMDb. Provider links go to TMDB's regional availability page; not guaranteed direct streaming links. TMDB and JustWatch attribution included; add the approved TMDB logo before public launch as required by their branding rules.
